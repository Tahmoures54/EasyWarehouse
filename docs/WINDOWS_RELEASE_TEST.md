## آماده‌سازی

- [ ] فایل `EasyWarehouse.exe` را از Artifact با نام `EasyWarehouse-Windows-x64` دریافت کنید.
- [ ] ZIP را استخراج کنید و SHA-256 فایل EXE را ثبت کنید.
- [ ] روی Windows تمیز که Python نصب ندارد اجرا کنید.
- [ ] اگر Windows SmartScreen یا آنتی‌ویروس هشدار داد، متن دقیق هشدار و نتیجه را ثبت کنید؛ هشدار را نادیده نگیرید.

## شواهد لازم

- [ ] تصویر یا ویدئو از اجرای اولیه برنامه
- [ ] تصویر فهرست کالا و موجودی پس از ورود/خروج
- [ ] تصویر پیام جلوگیری از خروج بیش از موجودی
- [ ] تصویر بازیابی موفق پشتیبان
- [ ] تصویر رد فایل پشتیبان خراب
- [ ] ثبت متن کامل هر خطا و نام سناریو
- [ ] ثبت SHA-256 فایل آزموده‌شده و commit مربوط به آن

## تصمیم نهایی

- [ ] همه سناریوها قبول شدند؛ آماده بررسی نهایی انتشار
- [ ] یک یا چند سناریو رد شد؛ انتشار متوقف و مشکل باید اصلاح و دوباره آزموده شود
- [ ] آزمون روی Windows تمیز/بدون Python انجام نشد؛ وضعیت همچنان «آماده آزمون انتشار» است، نه «تأییدشده برای پروداکشن»

**قاعده:** سناریویی که اجرا نشده یا برای آن مدرک وجود ندارد، «تأییدنشده» ثبت می‌شود؛ نه «قبول».
